慢操作任务丢后台

对话仍可以保持响应，工具调用带着参数，background_tasks
开启子线程。主会话添加结果占用位置
关键字触发后台任务，例如 pip install  npm install  yarn install docker build python - m build 

启动任务时添加判断，是否时后台任务，if should_run_background，或者判断启发式兜底，判断是不是在某些任务列表判断 name是否是bash。如果是bash，判断是不是在慢操作列表
