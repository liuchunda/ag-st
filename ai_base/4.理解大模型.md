# 大模型LLM是什么
- 大语言模型（LLM） 是在海量文本上训练出来的 AI 模型，能理解和生成自然语言。
「大」体现在：训练数据大、参数量大、算力消耗大、能力覆盖面大。
对使用者来说，大模型是一个输入文字 → 输出文字的服务。
代表性产品：ChatGPT、通义千问、DeepSeek、Claude 等，底层都是大语言模型。

# GPT 与 ChatGPT 的关系
- GPT（Generative Pre-trained Transformer） 是 OpenAI 推出的一系列生成式预训练模型。
- ChatGPT 是在 GPT 基础上，经过对话微调和人类反馈优化后的聊天产品。
- 关系可以简化为：GPT 是引擎，ChatGPT 是装上了方向盘和仪表盘的车。

# 发展时间线
- 2017：Google 提出 Transformer 架构，成为现代大模型的基础。
- 2018～2020：GPT-1 / GPT-2 / GPT-3 陆续发布，生成能力越来越强。
- 2022 年底：ChatGPT 发布，大模型进入大众视野。
- 2023 至今：GPT-4 及各家多模态、推理模型快速迭代。

# 分词
- 为什么需要分词？因为大模型的输入输出都是「词」的序列，输入一句话，模型需要先把句子拆成一个个词，才能理解和处理。
