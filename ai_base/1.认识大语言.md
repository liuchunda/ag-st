# 什么是人工智能【ai】

- 让机器模拟人类智能的技术，包括学习推理判断能力。


# 什么是大模型：大语言模型【LLM】大视觉模型【】视频大模型【】

- 传统 AI：擅长单一任务，如人脸识别、垃圾邮件过滤，每个任务往往要单独训练。
- 大模型时代：一个模型能处理多种语言任务——聊天、翻译、摘要、写代码等。
- 你可以把大模型理解成「读过海量文本、会组织语言回答问题的超级助手」。
- 我们日常用的 ChatGPT、通义千问、DeepSeek 对话，背后都是大语言模型。


# 机器学习与深度学习 【ML】

- 机器学习：让程序从样本数据中自动找规律，而不是人写死每一条规则。
- 深度学习：机器学习的一个分支，用多层「神经网络」处理复杂数据（文字、图片、声音）。
- 大语言模型属于深度学习，专门处理自然语言（人类日常使用的文字）。属于人类语言分支的深度学习，所以大模型属于机器学习


人工智能（AI）：让机器表现出类似智能的能力（很宽的目标）。实现路径：【机器学习，知识推理，搜索规划...】
机器学习（ML）【子领域：深度学习，监督学习，强化学习】：实现 AI 的主要路径之一——从数据里学规律，而不是把规则全写死。
深度学习（DL）：机器学习的一个子领域，用多层神经网络从数据中学表示。
    
大模型：规模特别大的深度学习模型；其中 大语言模型（LLM） 主要面向文本；还有多模态大模型等。

人工智能是一个目标研究方向，机器学习是实现的一条路径【机器学习，知识推理，搜索规划...】，深度学习是机器学习的一个子领域【子领域：深度学习，监督学习，强化学习】，大模型是规模特别大的深度学习

# 自然语言处理（NLP）是什么
NLP（Natural Language Processing） 是研究「计算机如何理解、处理人类语言」的领域。
典型任务：机器翻译、情感分析、文本摘要、问答对话。

# 什么是 Token
Token 是大模型处理文本的最小单位，可以是一个字、一个词，或词的一部分。
英文里 1 个 token 大约对应 3～4 个字符；中文里 1 个汉字往往接近 1 个 token。
模型有上下文窗口限制，例如「8K」「128K」表示一次最多能处理多少 token。
对话越长、输入越多，消耗的 token 越多，调用费用通常也越高（按量计费时）

# AGI 与 AIGC
AIGC 是当前 AI 技术的重要应用方向，AGI 是长期的终极目标；AIGC 的发展为 AGI 积累了必要的技术基础，但 AGI 还需突破更高层的认知与推理能力。
