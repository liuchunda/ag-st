#### 1. e2e 端到端自动化测试系统｜项目发起人 / 架构负责人

**做法与亮点**：
- 设计 **三层架构**（编排层 / 资产层 / 运行时）+ **多角色 Agent**（Lead 调度、Developer 生码、Tester 执行、审计员评审），通过上下文隔离降低长链路注意力稀释

- 多端代码模式混用问题：先收敛「端 → 范围 → 生成/跳过」，再进入 e2e 生码，提升可执行率

**收益**：覆盖约 **80%** 测试工作量，测试效率提升约 **70%**；已落地小米信息部。
